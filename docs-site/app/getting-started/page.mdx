# Getting Started

Sign up, then follow the in-app **Welcome tutorials** to go from zero to a deployed API.

<Callout type="important">
  **You can skip the docs and learn in the app.** After you log in, live tutorials on the dashboard teach you everything you need—step by step, while you do the work. We're continually expanding them so more of the platform is covered without reading documentation.

  Reopen tutorials anytime from the **inbox** in the top right of the dashboard.
</Callout>

## Quick start

The welcome tutorials walk you through each step below in order.

<Steps>
### Sign up

Sign up with Google or GitHub on the [login page](/login). BaaSForge opens the **Welcome to BaaS Forge** dialog on your first visit.

### Your first project

Get familiar with the dashboard and create your first project.

### Write and call your API

Describe an API in the project chat, review the generated units, deploy to **stage**, and call your endpoint with the built-in HTTP client.

### Debug and release

Use **traces** to see what happened on each request, ask the AI what went wrong, update your units, redeploy to stage, then **release to production**.
</Steps>

## What you will have done

By the end of the tutorials you will have:

- Created a project
- Written and called an API
- Traced and debugged a request
- Released to production

<Callout>
  To roll back to an older release, see [Release History & Rollback](/development/release-history). A dedicated **Units and rollbacks** tutorial is on the way.
</Callout>
