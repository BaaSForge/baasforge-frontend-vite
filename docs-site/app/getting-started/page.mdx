# Getting Started

Create an account, open the dashboard, and spin up your first project in
a few minutes.

## 1. Sign in

Go to [baasforge.com/login](/login) and authenticate with your account.

## 2. Create a project

From the dashboard, create a new project. Give it a clear name — this
becomes the root for your APIs and conversations.

## 3. Open a conversation

Use the project conversation to describe the API you want. BaaSForge
helps you generate units and wire them into a runtime.
