# Deployment

Publish a release from a project conversation, then point clients at the
generated runtime URL.

## Create a release

When your units look good, create a release. Each release is immutable
and can be shared via documentation links.

## Environments

Use stage for validation and production for live traffic. Keep secrets
out of client bundles — configure them in the runtime settings.
