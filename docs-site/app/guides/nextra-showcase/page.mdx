# Nextra Components Showcase

This page demonstrates the Nextra docs theme and components available in
the BaaSForge documentation site. Breadcrumb, table of contents,
pagination, and last updated are provided automatically by the theme
wrapper.

## Theme features

- **Breadcrumb** — shown above the page title
- **Table of contents** — right sidebar from page headings
- **Copy page** — button above content copies this page as Markdown
- **Pagination** — previous/next links at the bottom
- **Last updated** — bottom-right timestamp on every page
