# Releases

Releases freeze a project state so you can deploy and share stable API
documentation.

## List releases

```http copy
GET /api/projects/:projectId/releases
```

## Create release

```http copy
POST /api/projects/:projectId/releases
Content-Type: application/json

{
  "label": "v1.0.0"
}
```
