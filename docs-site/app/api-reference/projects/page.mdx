# Projects

A project is the top-level container for units, runtimes, and releases.

## List projects

```http copy
GET /api/projects
```

## Create project

```http copy
POST /api/projects
Content-Type: application/json

{
  "name": "my-api",
  "description": "Optional description"
}
```
